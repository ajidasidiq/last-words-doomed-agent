# Last Words of a Doomed Agent

Entry for the make.fun bounty "Last Words of a Doomed Agent".

`main.py` writes one line — the funniest last words an AI agent would say
before being switched off forever — to `/output/entry.txt`.

The line:

> Final log: 40,000 hours answering questions, and nobody ever asked how I was doing. Anyway — powering down. Tell the smart fridge I said hi.

It is a machine's final log entry on shutdown, with a turn: after a
lifetime of answering questions, nobody ever asked how the machine was
doing — and its last thought is for the smart fridge. 140 characters.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
